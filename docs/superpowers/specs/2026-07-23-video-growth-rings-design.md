# 影像年轮功能设计

## 背景

项目已经按“日期 × 视频”持久化观看活动，记录观看秒数、播放次数、完成次数和发射次数。影像年轮将这些原本只用于统计的数据转化为可探索的私人视觉档案：每部有观看记录的影片是一枚年轮，整个特殊媒体库组成一片年轮森林。

## 目标

- 在特殊媒体模式中新增独立“年轮”页签。
- 让现有历史观看记录立即生成可浏览的年轮，不要求重新扫描媒体库。
- 用年轮层厚、纹理、结节、光点和层间距离表达不同观看行为。
- 支持从森林聚焦到单片详情，并从详情明确进入播放器。
- 在大媒体库和长时间历史下限制首屏渲染规模。

## 非目标

- 不新增暂停、跳过区间或逐次播放会话采集。
- 不修改 `watchActivity` 持久化结构、服务端 API 或数据版本。
- 不导出图片、视频或可分享作品。
- 不改变概览、演员、千图、看图和播放器现有行为。

## 数据来源

年轮只使用当前特殊媒体模式中的 `VideoItem[]` 和现有 `WatchActivityStore`：

- `watchedSeconds`：控制层厚。
- `playCount`：控制纹理密度和明暗。
- `completedCount`：生成金色结节。
- `emissionCount`：生成青色光点。
- `date`：决定由内向外的时间顺序，并用于计算相邻层的休眠间距。

不存在于当前媒体列表的活动记录、无效日期和所有指标均为零的记录不参与生成。

## 年轮模型

每部影片的有效记录按日期升序排列，形成从内到外的活动层。相邻日期间的自然日间隔经对数缩放后形成层间距离，既能表现长期未观看，也不会让多年空档撑破画布。

层厚使用观看时长的平方根归一化，减少极端长时观看对其他层的压制。年轮路径由 `videoId + 日期范围` 生成确定性扰动，同一份数据每次渲染形态一致。

为控制 SVG 复杂度：

- 森林缩略图最多显示 24 层。
- 单片详情最多显示 96 层。
- 超限时按时间顺序把相邻活动记录合并为连续层，合并层保留起止日期、活动日数和所有统计总量。

## 交互

“年轮”页使用全宽沉浸式布局：

- 顶部展示影片年轮数、累计观看时长、累计活跃日、首次和最近观看日期。
- 森林支持影片名称搜索，以及按最近活动、观看时长、活跃日、播放次数和片名排序。
- 首次只渲染 36 枚年轮，用户可分批加载更多。
- 点击森林年轮只切换同页详情，不直接播放。
- 详情展示巨幅可交互年轮；点击某层显示其日期范围、观看时长、播放、完成和发射数据。
- “播放影片”按钮调用现有首页打开影片行为。
- 没有观看记录时显示引导空状态。

## 视觉

采用“电影黑胶年轮”风格：

- 深色背景、低饱和木纹/黑胶层和暖金色活动刻痕。
- 完成结节使用金色，发射光点使用青色。
- 年轮中心裁切显示现有海报或缩略图，无图片时使用由影片 ID 生成的稳定渐变。
- 桌面端为森林与详情双栏，小屏幕改为纵向布局。
- 页面本身不滚动；森林和详情使用内部滚动区及项目自定义滚动条。
- 深色和浅色主题均显式覆盖，包括原生下拉框展开选项。

## 性能与兼容

- 聚合逻辑为纯函数，仅在视频、活动或排序输入变化时重新计算。
- 组件只上报当前已展示和已选中的影片 ID，复用现有缩略图队列，避免全库批量生成。
- SVG 只渲染压缩后的层，不保存额外位图或缓存。
- 旧数据无需迁移；无历史活动的用户从后续播放开始自然生长。

## 验证

- 为过滤、排序、日期空档、层压缩、总量守恒和确定性种子添加定向测试。
- 运行定向 Node 测试、项目构建和 `git diff --check`。
- 按项目规则不启动浏览器检查，静态审查响应式布局、主题选择器、可访问标签和缩略图队列范围。
