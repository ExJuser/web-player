# 全屏烟花发射动画设计

## 目标

重新设计特殊模式“发射”按钮的反馈动画，在不改变发射次数记录逻辑的前提下，提供约 3 秒、覆盖整个视口的高密度烟花效果。动画不阻塞页面操作、不播放声音，并在结束后自动清理。

## 视觉节奏

1. **升空（0–0.55 秒）**：金色火箭从屏幕底部冲向中央，带发光尾焰和少量火星。
2. **主爆炸（0.45–1.25 秒）**：中央出现短促白金闪光和双层冲击波，随后绽放主烟花。
3. **连锁烟花（0.8–2.45 秒）**：紫、蓝、金、粉烟花在多个屏幕位置错峰爆炸，粒子带拖尾、重力下坠和亮度衰减。
4. **火星雨与淡出（2.2–3 秒）**：最后一轮烟花铺开，残余火星自然下落，遮罩与粒子同步淡出。

## 实现方案

采用 Canvas 粒子系统与 CSS 覆盖层的混合方案：

- `RocketLaunchEffect` 负责创建全屏固定定位覆盖层和 Canvas，并在组件挂载时启动动画。
- Canvas 使用 `requestAnimationFrame` 绘制火箭、烟花粒子及拖尾；烟花批次、颜色和爆炸位置由预设时间线控制，保证每次发射稳定且丰富。
- CSS 元素负责暗色氛围遮罩、主爆炸闪光和冲击波，避免 Canvas 承担大面积渐变效果。
- Canvas 尺寸随视口变化，设备像素比设置上限，避免高分屏产生不必要的粒子绘制成本。
- 现有 `launchEffectKey` 继续负责重新挂载动画；计时器延长到与新动画总时长一致，结束后卸载组件。

## 组件边界与数据流

- `SpecialStatsControl` 和发射按钮保持不变。
- `App` 点击处理仍先触发动画，再更新发射统计；只调整动画卸载时间。
- `PlayerStage` 仍按 `launchEffectKey` 条件渲染 `RocketLaunchEffect`。
- `RocketLaunchEffect` 内部封装全部视觉状态，不向业务层暴露粒子或时间线细节。

## 交互、性能与无障碍

- 覆盖层保持 `pointer-events: none` 和 `aria-hidden="true"`，不抢占焦点或点击。
- 动画卸载时取消 `requestAnimationFrame` 并移除窗口尺寸监听，防止残留任务。
- 限制粒子总量与设备像素比；页面不可见时不继续生成新烟花。
- `prefers-reduced-motion: reduce` 下不运行粒子系统，仅显示短暂、低强度的中央闪光。

## 验证范围

- 静态检查组件生命周期、计时器时长、事件清理和 CSS 层级。
- 确认连续点击会重新开始动画且统计仍只按点击次数递增。
- 确认普通、全屏和影院模式下覆盖层均铺满视口。
- 确认减少动态效果模式不会运行完整粒子动画。

不修改发射统计结构、播放器业务流程、按钮布局或其他页面动画。
