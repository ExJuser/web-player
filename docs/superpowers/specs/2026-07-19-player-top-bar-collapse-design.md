# 播放器顶部信息折叠设计

## 目标

- 播放器顶部默认只显示“影片信息”摘要，减少横向拥挤。
- 悬停摘要时以动效展开影片元数据；点击后固定展开，按 Esc 或点击外部收起。
- 仅在确有播放风险时展示兼容性提示，例如帧率或码率过高；提示随影片信息一起折叠。
- 移除播放器顶部的“看图”“新增媒体库”“本地缓存”入口。

## 交互设计

影片信息沿用现有“播放数据”控件的交互语义和动效：桌面端支持悬停展开，所有设备支持点击切换固定状态，并保留键盘焦点、Esc 和点击外部收起能力。默认摘要保持单行紧凑尺寸；展开区域展示现有元数据标签和风险提示。

“视频可直接播放”、兼容性探测中的普通状态和“生成修复 MP4”按钮不再显示。兼容性文案仅在现有结果明确表示播放风险时出现，不改变底层探测或媒体处理逻辑。

## 修改范围

- `src/PlayerTopBar.tsx`：增加折叠状态与交互，精简兼容性展示和顶部按钮。
- `src/App.tsx`：移除 `PlayerTopBar` 不再需要的回调和状态属性传递。
- `src/styles.css`：增加影片信息折叠/展开样式、响应式布局和减弱动画适配。
- 必要时补充最小范围 UI 结构测试；不改动其他页面入口和底层功能。

## 验收标准

- 播放器视图有当前影片时，顶部默认只显示“影片信息”。
- 悬停、点击、键盘操作的展开/收起行为与“播放数据”一致。
- 展开后显示原有影片元数据；只有播放风险提示会出现。
- 顶部不再出现“看图”“新增媒体库”“本地缓存”。
- 深浅色和窄屏样式保持可读，减弱动画设置下不执行过渡动画。
