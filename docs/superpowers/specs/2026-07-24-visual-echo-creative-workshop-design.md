# 画面回声与创意工坊设计

## 背景

特殊模式已经包含千图成像和影像年轮，但它们与“概览”“演员”并列，功能分类不清晰。画面回声需要把当前影片画面与媒体库中的采样帧进行本地视觉相似度比较，也属于同一类创意工具。

## 目标

- 顶层只保留“概览 / 演员 / 创意工坊”，在工坊内整合千图、年轮和画面回声。
- 支持从播放器当前时间点或工坊内任意影片时间点发起回声搜索。
- 使用本地视觉特征完成匹配，不依赖云端 AI。
- 结果可跳转到来源影片的准确时间点，并可继续以结果为源搜索。
- 索引仅由用户主动构建，可取消、增量更新并持久化到项目数据目录。

## 非目标

- 不做播放中的持续后台分析或时间轴自动标记。
- 不进行人物、动作或语义识别；“相似”仅表示构图、色彩和明暗结构接近。
- 不在首页或媒体库扫描阶段批量运行 ffmpeg、ffprobe 或视频解码。
- 不修改 `PlayerDataStore` 和现有播放数据迁移逻辑。

## 创意工坊导航

`specialHomeSection` 收敛为 `overview | actors | creative`，另设 `creativeFeature: mosaic | rings | echo | null`。进入“创意工坊”先展示三张功能卡，进入功能后显示返回工坊入口。

创意区使用全宽剩余高度，隐藏继续观看和右侧栏。千图从图集阅读页返回时恢复到 `creative + mosaic`；年轮现有查询、排序、选中层和分页状态仍保存在 `App`。

## 视觉回声索引

每部影片根据时长生成 6–24 个均匀采样时间点，约每五分钟一帧，范围限制在影片 5%–95%。使用浏览器可播放 URL 顺序解码，无法解码的影片跳过并计入状态。

每个采样帧生成：

- 3×3 Lab 区域色彩描述符；
- 9×8 差异哈希；
- 6×4 明暗构图网格；
- 320×180 WebP 预览。

相似度由差异哈希 45%、构图明暗 35%、区域色彩 20% 合成。默认排除来源影片，最多返回 18 条稳定排序结果，可切换为包含同片。

视频签名包含算法版本、`videoId`、`size` 和 `lastModified`。读取索引时过滤失效签名，构建时只处理缺失或失效影片。取消时保留本轮已经完成的视频。

## 持久化

新增 `.local-web-player-data/visual-echo/`：

- `index.json` 保存版本、更新时间和样本描述符。
- `frames/` 保存稳定 frame ID 对应的 WebP 预览。

提供索引读取、写入、删除和帧读写 API。写入索引后清理不再引用的帧。服务端不可用时保留内存索引和对象 URL，并提示本次会话结束后失效。

画面回声目录加入本地缓存状态和清理列表。

## 交互

工作台提供索引概况、构建/更新/取消、影片筛选、时间滑杆、源画面、搜索结果和叠化比较。播放器快捷入口只在特殊模式且有当前影片时出现；点击后保留当前 `videoId + currentTime` 并进入工作台。

结果卡显示影片、时间和相似度。详情支持调节源画面与结果画面的叠化比例、“跳转到此处”和“以此为源”。精确跳转通过一次性初始时间 ref 覆盖普通历史进度，使用后立即清除。

## 性能与失败处理

- 同一时间只解码一部影片，复用单个视频元素和画布。
- 所有长任务使用 `AbortController`，状态在 `finally` 中复位。
- 帧对象 URL 在替换或卸载时回收。
- 单帧失败不终止整部索引；整部无法加载时记录跳过。
- 所有提示使用就近状态，不使用原生弹窗。

## 验证

- 定向测试采样时间、描述符、评分、过滤、增量签名和服务端缓存。
- 运行 TypeScript/Vite 构建及 `git diff --check`。
- 按项目规则不打开浏览器。
