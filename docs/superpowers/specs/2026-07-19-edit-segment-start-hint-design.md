# 剪辑起点提示设计

## 目标

用户首次点击剪辑按钮、进入等待选择终点的状态后，在播放器控制栏显示明显的起点时间提示。

## 交互

- 当前视频存在待完成的剪辑保留片段时，显示“剪辑起点 {时间}”。
- 提示位置、视觉样式和时间格式复用现有高能片段起点提示。
- 选择终点、切换视频或待选状态被清除后，提示随状态消失。
- 高能起点与剪辑起点可同时显示，并通过文案区分。

## 实现范围

- 将当前视频的剪辑待选起点时间传给 `PlayerControlBar`。
- 扩展 `PlayerHighlightControls`，在现有提示行中渲染剪辑起点提示。
- 不新增样式，不修改剪辑标记、保存或生成流程。

## 验证

按项目最小修改规则，仅检查属性传递、条件渲染、文案和 TypeScript 类型是否一致，不运行浏览器检查或全量测试。
