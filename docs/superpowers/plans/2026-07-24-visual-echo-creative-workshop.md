# 画面回声与创意工坊开发计划

**目标：** 整合创意功能入口，并实现可持久化、可增量构建的本地画面回声搜索。

**架构：** 纯算法模块负责采样、描述符和匹配；客户端运行时负责视频解码与帧上传；独立服务端存储负责索引和预览帧；`App` 负责创意导航与播放器精确跳转。

---

## 任务 1：视觉算法与运行时

- [ ] 定义索引、样本、描述符、查询结果和构建状态类型。
- [ ] 实现自适应采样、稳定签名/frame ID、描述符和综合评分。
- [ ] 实现索引过滤、默认跨影片匹配和最多 18 条稳定结果。
- [ ] 实现单视频顺序解码、WebP 预览生成、取消和会话回退。

## 任务 2：服务端缓存

- [ ] 新增 visual-echo store，原子写入索引与帧。
- [ ] 新增索引和帧 API，写索引时清理孤立帧。
- [ ] 将画面回声缓存加入缓存状态与清理入口。
- [ ] 添加服务端 store 定向测试。

## 任务 3：创意工坊与工作台

- [ ] 重构特殊模式导航为“概览 / 演员 / 创意工坊”。
- [ ] 新增千图、年轮、画面回声三张工坊卡片和返回入口。
- [ ] 保持千图图集返回链路及年轮现有状态。
- [ ] 新增索引控制、源影片时间选择、结果网格和叠化详情。

## 任务 4：播放器接入

- [ ] 顶部增加特殊模式画面回声快捷入口。
- [ ] 携带当前影片和时间进入工作台并在已有索引时自动搜索。
- [ ] 增加一次性精确时间 ref，结果跳转优先于历史进度。
- [ ] 支持以结果画面继续搜索。

## 任务 5：验证与提交

- [ ] 运行视觉算法与服务端缓存定向测试。
- [ ] 运行项目构建和补丁格式检查。
- [ ] 静态审查主题、移动布局、取消路径和对象 URL 回收。
- [ ] 提交功能代码且不暂存现有 pnpm 文件。
