# 影像年轮功能开发计划

**目标：** 在特殊媒体模式中增加全宽年轮森林，并支持同页查看单片可交互年轮详情。

**架构：** 新增纯函数模块，把 `WatchActivityStore` 聚合为影片年轮模型；新增独立 React 区域组件负责搜索、排序、渐进加载、SVG 年轮和详情交互；`App.tsx` 只负责页签接入、打开影片和可见缩略图队列。

**技术栈：** React、TypeScript、SVG、CSS、Node test runner。
